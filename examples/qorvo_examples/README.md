# Qorvo examples ported to run on DWM3001CDK
These are the examples provided in Qorvo's DW3_QM33_SDK_1.1.1.
Examples are modified slightly to build and run on DWM3001CDK.

## Example selection
Select an example to build in examples/qorvo_examples/example_selection.h

Please enable only one example at a time.

## Build steps using nRF Connect SDK
1. Open nRF Connect in vscode
2. Open an existing application > Select examples/qorvo_examples/ex_main
3. Add Build Configuration > Board target > Select `decawave_dwm3001cdk/nrf52833`
4. Generate and Build
